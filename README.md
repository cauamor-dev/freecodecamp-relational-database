# Relational Database projects

Original Bash and PostgreSQL solutions recovered from the existing freeCodeCamp Relational Database V8 Codespaces on October 5, 2026.

- `salon.sh` and `salon.sql`: appointment scheduler with customers, services and appointments.
- `element.sh` and `periodic_table.sql`: element lookup by atomic number, symbol or name.
- `number_guess.sh` and `number_guess.sql`: number guessing game with user statistics.

The scripts and the Periodic Table and Number Guessing SQL files are unchanged copies of the preserved originals. `salon.sql` is a new read-only export of the existing Salon database made on October 5, 2026; it was not an existing historical SQL file.

These files are being prepared for support review of a progress synchronization issue. Their presence does not establish that course credit or a certificate has been issued. Bash syntax was checked during recovery; the original course tests were not rerun.

Use a disposable PostgreSQL environment when reviewing the original SQL dumps. The Periodic Table and Number Guessing dumps include their original database drop/recreate statements.

The private recovery report and support draft are separate from the proposed public repository contents.
